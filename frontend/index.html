ℹ️ Sobre o Sentinela

🎯 O que é?

O Sentinela é um sistema de busca unificada que agrega dados de múltiplas fontes públicas de diários oficiais brasileiros, utilizando apenas APIs gratuitas e projetos open-source.

✨ Características

  • ✅ 100% Gratuito - Apenas APIs públicas
  • ⚡ Busca Paralela - Consultas simultâneas
  • 🔄 Dados Normalizados - Formato JSON unificado
  • 📚 Ampla Cobertura - Centenas de fontes
  • 🔓 Código Aberto - MIT License

📋 Fontes Integradas

  • Querido Diário - 600+ municípios brasileiros
  • DataJud/CNJ - Todos os tribunais
  • TCU - Tribunal de Contas da União
  • DOU - Diário Oficial da União (em desenvolvimento)

🔧 Tecnologias

Backend: Python 3.10+, FastAPI, httpx (assíncrono)
Frontend: HTML5, CSS3, JavaScript Vanilla
APIs: Querido Diário, DataJud/CNJ, TCU Dados Abertos
